# 📝 Todo List App

A stylish and interactive Todo List web app to help you stay organized and productive! Built with **HTML**, **CSS**, and **JavaScript**, it supports adding, filtering, completing, and deleting tasks — all in a beautiful UI.

## ✨ Features

- ✅ Add and remove tasks
- 📋 Filter tasks (All / Pending / Completed)
- 🗑️ Clear completed or all tasks
- 📈 Live task count & completed stats
- 🎨 Beautiful, responsive design
